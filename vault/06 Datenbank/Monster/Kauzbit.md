# Kauzbit

![[Kauzbit_32_x4.png|192]]

**Element:** Code | **Stufe:** 1 (Baby) | **Tier:** Robo-Eule

## Beschreibung
Eine kleine Roboter-Eule aus weißen und mintgrünen Metallplatten mit großen, leuchtenden Kameralinsen-Augen. Sie sieht Angriffe kommen, bevor sie passieren.

## Passiv: Eulenblick
Sieht Angriffe früher: Warnungen erscheinen 0,3 s eher.

## Signatur: Scanblick
Scannt den Gegner: 15 Schaden, deine nächsten 3 Treffer machen +50 %.

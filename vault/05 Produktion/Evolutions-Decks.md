# Evolutions-Decks

Jede entwickelte Form startet einen Run mit eigenem 8-Chip-Deck (Code: `EVO_DECK` in `prototype/index.html`). Babys starten mit dem Basis-Deck aus `MONS`.

**Bauplan:** 4–6 Chips des eigenen Elements + Signatur-Chip + 2–3 neutrale Chips (Pixelstrahl/Byteschlag). Champion/Ultra sind noch stärker auf ihr Element fokussiert.
